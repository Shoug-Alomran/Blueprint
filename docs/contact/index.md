## What Makes a Strong Inquiry { #what-makes-a-strong-inquiry }

<div class="bp-split" markdown="0">
  <div class="bp-panel">
    <h3>Strong Inquiries Include</h3>
    <ul class="bp-check">
      <li>A clear target audience</li>
      <li>A defined purpose for the website</li>
      <li>Confirmation that the project fits static website scope</li>
      <li>Organized content — bio, CV, chapters, materials</li>
    </ul>
  </div>
  <div class="bp-panel bp-panel--muted">
    <h3>Likely Not a Fit</h3>
    <ul class="bp-nope">
      <li>Projects requiring databases</li>
      <li>Authentication or user accounts</li>
      <li>Dynamic, application-style systems</li>
      <li>SaaS platform development</li>
    </ul>
  </div>
</div>
