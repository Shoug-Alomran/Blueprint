<p class="bp-band__label">The Workflow</p>

## Delivery Stages { #delivery-stages }

<ol class="bp-flow" markdown="0">
  <li data-step="01">
    <h3><a href="intake-fit-check/">Intake &amp; Fit Check</a></h3>
    <p>Confirm project type, scope, and tier before any work begins.</p>
  </li>
  <li data-step="02">
    <h3><a href="discovery/">Discovery</a></h3>
    <p>Define goals, audience, content readiness, and required sections. Scope is locked here.</p>
  </li>
  <li data-step="03">
    <h3><a href="structure-sitemap/">Structure &amp; Sitemap</a></h3>
    <p>Build and approve the navigation hierarchy and content map before any visual work begins.</p>
  </li>
  <li data-step="04">
    <h3><a href="build/">Build</a></h3>
    <p>Implement the responsive static layout, typography system, and all deliverables — including HTML report conversion where included.</p>
  </li>
  <li data-step="05">
    <h3><a href="revision-rounds/">Review &amp; Revisions</a></h3>
    <p>Refine clarity, organization, and presentation within agreed scope boundaries.</p>
  </li>
  <li data-step="06">
    <h3><a href="deployment-handover/">Deployment &amp; Handover</a></h3>
    <p>Publish to production, run final checks, confirm payment, and transfer ownership.</p>
  </li>
</ol>

<p class="bp-band__label">Why It Works</p>

## What This Process Protects { #what-this-process-protects }

<div class="bp-tiles bp-tiles--3" markdown="0">
  <article class="bp-tile">
    <span class="bp-tile__num">Guarantee 01</span>
    <h3>Scope Control</h3>
    <p>Each stage is locked before the next begins. Out-of-scope additions are quoted separately before any implementation.</p>
  </article>
  <article class="bp-tile">
    <span class="bp-tile__num">Guarantee 02</span>
    <h3>Quality Assurance</h3>
    <p>Defined validation conditions at each stage prevent rework later.</p>
  </article>
  <article class="bp-tile">
    <span class="bp-tile__num">Guarantee 03</span>
    <h3>Predictable Delivery</h3>
    <p>Clear milestones and documented handover reduce uncertainty for both sides.</p>
  </article>
</div>
